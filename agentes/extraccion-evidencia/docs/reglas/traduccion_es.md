# Traducción al español (columnas H, I, J de `Tablas_capa_1`)

Estilo: neutro, técnico, igual al de las filas existentes (revisadas por el equipo). Traducir todo salvo siglas y nombres propios de bases de datos o instituciones sin traducción oficial.

## Formato numérico

Coma decimal, punto para miles: `85,4%`, `85.050`, `0,42`. Rangos con guion: `(IC del 95%: 80,8 - 88,9)`.

## Glosario

| Inglés | Español |
|---|---|
| vaccine effectiveness / VE | efectividad de la vacuna / EV |
| 95% CI | IC del 95% |
| Not reported | no reportado |
| vaccinated / unvaccinated | vacunados / no vacunados |
| cases / controls | casos / controles |
| individuals aged ... | individuos de ... (años) |
| ... and older / ... or younger | ... o más / ... o menos |
| all ages | todas las edades |
| Observation period | Período de observación |
| Data from | Datos de / Datos del |
| Comparison | Comparación |
| pre-vaccination period versus post-vaccination period | período prevacunación versus período posvacunación |
| ecological before-and-after study | estudio ecológico de antes y después |
| outbreak investigation cohort study | estudio de cohorte de investigación de brote |
| prospective cohort study | estudio de cohorte prospectivo |
| retrospective cohort study | estudio de cohorte retrospectivo |
| test-negative case-control study | estudio de casos y controles con diseño de prueba negativa |
| self-controlled case series | serie de casos autocontrolada |
| matched cohort | cohorte emparejada |
| hospitalization / discharges | hospitalización / altas |
| emergency department visits | consultas al servicio de urgencias |
| rate per 100,000 population | tasa por 100.000 habitantes |
| Reduction in ... rate | Reducción de la tasa de ... |
| Contracting the disease was measured as | Se consideró que una persona contrajo la enfermedad si presentó ... |
| Disease occurrence was measured as | La ocurrencia de la enfermedad se midió como ... |
| statistically significant / not | estadísticamente significativa / no |
| United States / United Kingdom | Estados Unidos / Reino Unido |
| Non-comparative study | Estudio no comparativo |
| The study described / reported | El estudio describió / informó |

Cuando el usuario corrija una traducción, agregar el par al glosario (lo hace `/aprender-correccion`).
